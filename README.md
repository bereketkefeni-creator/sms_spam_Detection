# 📱 SMS Spam Detection

A machine learning project to classify SMS messages as **Spam** or **Ham** using Natural Language Processing (NLP) techniques.

---

  Project Overview
This project demonstrates how to build a text classification pipeline for detecting spam messages.  
It covers:
- Data cleaning and preprocessing
- Feature extraction with Bag of Words / TF-IDF
- Model training (Naive Bayes, Logistic Regression, etc.)
- Evaluation with accuracy, precision, recall, and F1-score

---

  Dataset
The dataset used is the **SMS Spam Collection Dataset**, which contains labeled SMS messages.  
Columns:
- `label` → Spam or Ham
- `message` → The SMS text
